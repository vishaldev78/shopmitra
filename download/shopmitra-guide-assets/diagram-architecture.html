ShopMitra ka System Design — Bada Naksha
Ek request browser se shuru hokar database tak kaise jaati hai, aur wapas kaise aati hai
1 · Browser (User ka phone / laptop)
React components · src/components/shop/
Pages (UI)Home, /products, /cart, /checkout, /admin — jo bhi user dekhta hai
AppContext (Global State)Cart, wishlist, user, banners — poore app ki yaaddasht
localStorageCart + wishlist browser me hi save hote hain (DB me nahi)
↓
fetch() — data maango
↑
JSON response — data mila
2 · Next.js Server (App ka dimaag)
src/app/api/**/route.ts + src/lib/
API Routes/api/auth, /api/products, /api/orders, /api/payments… — request aaye to ye chalte hain
auth.tsPassword check + session cookie banana/verify karna
payments.ts + dodo.tsPayment banana, verify karna, stock adjust karna
mailer.tsEmail bhejna (Resend) + EmailLog me record
↓
Prisma queries + HTTPS calls
3 · Data aur External Services
prisma/schema.prisma → PostgreSQL
PostgreSQL DatabaseUsers, Products, Orders, Banners… sabka sacha data (Neon hosting)
Dodo PaymentsOnline payment ka gateway — paisa collect karta hai
ResendOrder emails customer ko deliver karta hai
Simple niyam: Browser sirf dikhawa karta hai (UI). Sachai (truth) hamesha server pe rehti hai — total, stock, order status sab server khud calculate karta hai. Isliye koi galti ya cheating se order kharab nahi ho sakta.
