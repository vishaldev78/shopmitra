Order ki Poori Kahani — Checkout se Delivery tak
Customer ke "Place Order" dabane ke baad system me kya hota hai
Phase 1 · Order Banana (Order Creation)
1Checkout page par user address chunta hai aur "Place Order" dabata hai — /checkout
2Browser order bhejta hai: items + address + payment method (COD ya Dodo) → POST /api/orders
3Server sab khud check karta hai: stock hai? product active hai? coupon valid? — total, GST 18%, shipping (₹99, ₹999 upar free) server khud dobara calculate karta hai
4Order number banta hai SM-XXXXXX-XXXX aur ek transaction me order + items DB me save, stock minus — db.$transaction
↓
Phase 2 · Payment (2 raaste)
5aCOD (Cash on Delivery): status turant confirmed, stock kaat liya gaya, "Order placed" email chala gaya — khatam, seedha Phase 3
5bOnline (Dodo): status pending rehta hai → POST /api/payments/checkout Dodo par payment page banata hai → user pays
6Paisa confirm hone par: Dodo webhook ya confirm-poll kisi bhi ek se pata chalta hai → markOrderPaid() → status confirmed + stock minus + "confirmed" email
7Payment fail hua? markOrderFailed() → order cancel + "cancelled" email; stock waise bhi kata nahi tha
↓
Phase 3 · Delivery (Seller/Admin ka kaam)
8Seller/Admin dashboard se status badalta hai: pending → confirmed → shipped → delivered — PATCH /api/orders/[orderNumber]
9Har real status change par email jaata hai customer ko — sendOrderEmail(order, kind)
10Order cancel kiya? kata hua stock wapas add ho jaata hai (stock-conserving logic)
